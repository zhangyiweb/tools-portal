# QuickShare 快传

**局域网内快速传文件，告别 U 盘拷贝。**

QuickShare 是一款轻量级的局域网文件传输工具。你和同事连在同一个 WiFi 或有线局域网里，打开软件就能互相发现、直接传文件，不用插 U 盘、不用登录网盘、不用记 IP 地址。

适合日常办公互传文档、设计稿、安装包、视频等大文件，传输速度取决于局域网带宽，通常比 U 盘来回拷贝快得多。

---

## 功能特点

| 功能 | 说明 |
|------|------|
| 自动发现设备 | 同一局域网内的电脑会自动出现在列表中，无需手动输入 IP |
| 双向传输 | 任意一方都可以发送和接收文件 |
| 批量发送 | 支持选择多个文件，或一次性发送整个文件夹 |
| 实时进度 | 发送和接收过程均有进度条显示 |
| 完成提醒 | 传输结束或接收完成后会弹出提示窗口 |
| 自动保存 | 接收的文件自动保存到本地文件夹，重名文件自动加序号 |

## 下载与运行

### 直接使用（推荐）

1. 找到 `dist\QuickShare.exe`
2. 双击运行，或将 exe 复制给同事使用
3. 无需安装 Python，开箱即用

### 从源码运行

```bash
# 安装依赖
pip install -r requirements.txt

# 启动程序
python main.py
```

### 重新打包 exe

```bash
# 双击运行打包脚本
build.bat
```

打包完成后，可执行文件位于 `dist\QuickShare.exe`。

## 使用教程

### 第一步：确保在同一局域网

你和对方需要连接**同一个网络**，例如：

- 连接公司/家里的同一个 WiFi
- 通过网线接入同一台交换机或路由器

### 第二步：双方同时运行 QuickShare

各自双击 `QuickShare.exe` 启动程序。首次运行时，Windows 防火墙可能会弹出提示，请选择 **「允许访问」**，否则无法互相发现。

### 第三步：选择对方设备

程序启动后，左侧「局域网设备」列表会自动显示附近在线的同事电脑（显示为 `电脑名 (IP地址)`）。点击选中要发送的目标设备。

如果列表为空，可点击「刷新设备列表」，或确认对方也已打开 QuickShare。

### 第四步：选择并发送文件

1. 点击「选择文件」挑选单个或多个文件，或点击「选择文件夹」发送整个目录
2. 确认右侧文件列表无误
3. 点击「发送到选中设备」开始传输
4. 发送完成后会弹出提示窗口

### 第五步：接收文件

对方无需任何操作，文件会自动传送到其电脑上。接收完成后同样会弹出提示，文件保存在：

```
QuickShare.exe 同目录下的 QuickShare_接收文件 文件夹
```

点击界面底部的「打开接收文件夹」可快速查看已接收的文件。

## 常见问题

**Q：看不到对方的设备？**

- 确认双方都已运行 QuickShare
- 确认连接的是同一个 WiFi / 局域网
- 检查 Windows 防火墙是否已允许 QuickShare 访问网络
- 将网络类型设置为「专用网络」（设置 → 网络和 Internet → 属性）
- 部分公司网络可能屏蔽设备发现，可尝试手机热点测试

**Q：传输失败怎么办？**

- 传输过程中不要关闭 QuickShare 窗口
- 确认对方电脑没有休眠或断网
- 重新选择设备后再试

**Q：接收的文件保存在哪里？**

- 默认保存在 exe 同目录的 `QuickShare_接收文件` 文件夹
- 若文件名重复，会自动重命名为 `文件名_1`、`文件名_2` 等

**Q：支持多大的文件？**

- 理论上没有大小限制，采用分块传输，适合传大文件
- 实际速度取决于局域网带宽，千兆网络传 GB 级文件通常只需几分钟

## 技术说明

- **设备发现**：UDP 广播，自动扫描局域网内的 QuickShare 实例
- **文件传输**：基于 HTTP 协议，稳定可靠
- **大文件支持**：分块读写，内存占用低
- **界面框架**：CustomTkinter，深色主题
