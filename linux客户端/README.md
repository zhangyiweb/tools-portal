# 张怡 - 服务器管理客户端

面向前端同学的按钮式服务器管理工具（Java / Swing）。

## 功能

1. 顶部服务器栏：添加 / 编辑 / 连接（密码或私钥）
2. 左侧系统状态：环形图、趋势图、进程与磁盘
3. 文件管理：目录树 + 文件列表（上传 / 下载 / 删除）
4. 容器列表：启动 / 停止 / 重启 / 日志 / 删除 / 迁移，运行中可打开访问地址
5. 一键部署：安装 Docker / Nginx、部署静态站或反向代理、拉取并运行镜像

## 运行

```powershell
cd easy-ssh
java -jar target\easy-ssh-1.0.0.jar
```

或双击 `run.bat`。

服务器配置保存在 `~/.easy-ssh/servers.json`。
